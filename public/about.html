Disease Surveillance Dashboard

What this is

A student demonstration of a weekly disease surveillance dashboard for malaria, measles, cholera and yellow fever, shown by district. It was built for a university capstone project.

About the data

The dashboard uses only aggregated, public demonstration data from the DHIS2 demo database (Sierra Leone) and weekly Wikipedia pageviews. It holds no patient records. Reporting completeness is simulated, and the case numbers are not real.

Access

The dashboard itself is private and needs an account, because real surveillance data would be restricted to authorised staff. District officers see only their own district; national managers see all districts.
